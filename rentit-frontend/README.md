# RentIt Frontend Mock Website

A responsive rental management dashboard built with plain HTML, CSS, and JavaScript. No build tools or backend are required.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Publish with GitHub + Vercel
1. Create a GitHub repository (for example, `rentit-frontend`).
2. Upload `index.html` to the repository root and commit the changes.
3. Sign in to Vercel with GitHub at https://vercel.com/.
4. Choose **Add New → Project**, import the repository, and deploy.
5. For this plain HTML project, select **Other** if asked for a framework preset. No build command is needed.

## Demo features
- Dashboard summary cards and recent activity
- Property listings, search, status filters, details, add and edit forms
- Tenant list and add-tenant form
- Rental application review actions
- Messages, portfolio reports, and profile settings screens
- Responsive mobile sidebar

## Important
This is a frontend-only mock website. Data is stored in JavaScript arrays, so changes are temporary and reset when the page reloads. It does not have real authentication, a database, payments, or backend APIs.
